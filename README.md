一些小工具

- count-pacman-update：统计 pacman 滚动更新的次数
- gen-readme：自动生成 README.md，显示仓库文件结构
- md2html：markdown -> html
- on-second-screen：扩展第二个屏幕，参数 a、b、l、r 对应上下左右四个扩展方向
- off-second-screen：关闭第二个屏幕
- pdf-compress：压缩 pdf 文件
- pdf-merge：拼接 pdf 文件
- picture-merge：拼接图片
- toggle-testing：切换 pacman.conf 里 testing 仓库的注释状态
- video-cut：音视频文件剪切
